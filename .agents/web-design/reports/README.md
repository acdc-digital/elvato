# Web Design Reports

Completed design reviews and recommendations produced by the Web Design Agent.

## Naming Convention

```text
YYYY-MM-DD-<page-or-component>-review.md
```

Examples:

- `2026-06-23-product-page-review.md`
- `2026-06-23-homepage-hero-review.md`
- `2026-06-23-category-filtering-review.md`

## Standard

Use `../templates/design-review.md` for every report. Ground findings in the real implementation under `storefront/src/` and score against the seven lenses in `../manual/evaluation-framework.md`.
