## Visual Design & Brand Consistency

### Typography Assessment

**Current State: Substantially Improved (B+ grade, up from D+)**

The `font-mono` overuse has been fully resolved. The site now uses a coherent two-font system:

| Role | Font | Class/Var | Status |
|------|------|-----------|--------|
| Logo / Brand mark | Fraunces 900 italic | `var(--font-fraunces)` inline | Excellent — distinctive, premium |
| Body font (new) | Inclusive Sans (variable) | `--font-inclusive` → `font-sans` | Good — humanist sans-serif with warmth |
| All UI text | Inclusive Sans | `font-sans` | Correct — consistent application |
| Former mono overuse | System monospace | `font-mono` | Eliminated from user-facing text |

**Note**: The Tailwind config defines `font-sans` as `["var(--font-inclusive)", "Inter", ...]` — Inclusive Sans is loaded as a local variable font in `layout.tsx`. This is a better choice than Inter for a lighting brand — it has slightly more character and warmth.

**Remaining typography issues:**
1. **Hero H1 at `font-bold` is strong but the previous review suggested `font-extrabold`** — the current weight works well with the Inclusive Sans typeface. No change needed.
2. **Product card titles at `text-[13px]`** — appropriate for the card size but could go to `text-sm` (14px) for better mobile readability
3. **Section headers "Chandeliers", "Pendants" at `text-2xl font-light`** — the light weight is elegant but may lack impact. Consider `font-normal` for more presence while keeping the refined aesthetic
4. **"View all" links use the `InteractiveLink` component** — confirm these render in `font-sans` not `font-mono` from the UI preset

**Current State: Improved (B grade)**

## Strategic Recommendations

### Short-Term (1–2 weeks)

1. **Mobile navigation** — There is no hamburger menu or mobile drawer. Users on screens < 1024px see only the logo and cart icon with no way to navigate to About, How It Works, Design Services, or any category. This is a **critical UX gap**.

2. **Category mega-menu** — The single "Lighting" nav link serves 800+ products across 8+ categories. Implement a dropdown or mega-menu showing all categories with product counts, aligning with the hero badge lineup.

3. **Newsletter signup** — Add an email capture section above the footer. Lighting buyers often research across multiple sessions — email re-engagement is critical for this purchase cycle.

4. **"View all" link destination** — The `InteractiveLink` component should accept a collection handle and route to `/collections/{handle}` instead of `/store`.

### Medium-Term (2–4 weeks)

5. **Room-based filtering** — The Shop by Room section is visually strong but functionally dead. Build room-based collection pages or add room tags to products for filtered browsing.

6. **Product reviews integration** — The CTA banner claims "5.0 Rating" with no substantiation. Integrate a reviews platform (Judge.me, Loox, or Stamped) and display real review data on cards and the banner.

7. **Quick-add to cart** — Product cards lack any add-to-cart interaction. Add a hover overlay or persistent button for the default variant.

8. **Reduce free shipping threshold** — $1,500 is extremely high for a lighting store with average product prices of $100–400. Consider $500 or $750 to drive larger basket sizes without being unreachable.

### Long-Term (1–2 months)

9. **Lifestyle photography hero rotation** — The hero image is static. Implement seasonal or promotional hero rotation (spring outdoor lighting, holiday chandeliers, etc.).

10. **Trade/Professional program** — Interior designers and contractors are a key audience. Add a dedicated trade registration flow with trade pricing, project quotes, and spec sheet downloads.
