# Architecture Assessment Workflow

## Steps

1. Export or inspect Neon schema.
2. Export or inspect Convex schema.
3. Map current product, marketplace, inventory, pricing, media, and order flows.
4. Identify current system-of-record ownership.
5. Identify duplication, ambiguous ownership, and sync risks.
6. Design target architecture.
7. Produce roadmap by time horizon.

## Required Lens

Evaluate every recommendation against:

- 100,000 SKUs
- Multiple suppliers
- Multiple warehouses
- Multiple marketplaces
- Millions of historical records
- AI-generated enrichment and review workflows

## Deliverable Location

Save completed assessments to:

```text
.agents/architect/reports/YYYY-MM-DD-architecture-assessment.md
```
