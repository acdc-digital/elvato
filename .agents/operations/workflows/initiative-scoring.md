# Initiative Scoring Workflow

## Purpose

Rank possible work so Elvato does not confuse activity with value creation.

## Steps

1. Define each initiative in one sentence.
2. Identify the bottleneck it addresses.
3. Score revenue, profit, strategic value, difficulty, time to value, and risk.
4. Calculate priority score.
5. Identify dependencies and opportunity cost.
6. Choose the weekly winner.

## Formula

```text
Priority Score = (Revenue + Profit + Strategic Value) / (Difficulty + Risk)
```

## Caveat

Do not let a small easy task displace the highest-value initiative. Easy tasks should be sequenced as unlocks, not substitutes.
