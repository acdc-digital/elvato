# SEO Audit — Elvato Storefront

**Domain:** `https://elvato.shop`  
**Framework:** Next.js 15.3 (App Router)  
**Backend:** MedusaJS (Railway)  
**Image CDN:** Convex → Bunny CDN  
**Analytics:** Vercel Analytics + Speed Insights  
**Status:** Audit as of March 2026

---

## Executive Summary

The Elvato storefront has a **solid foundation** for SEO — server-side rendering via SSG/ISR, `metadataBase` configuration, `next/image` optimization, and Vercel Speed Insights for Core Web Vitals monitoring. However, there are **critical gaps** that must be addressed before expecting meaningful search rankings:

| Area | Status | Priority |
|------|--------|----------|
| Page titles & branding | ⚠️ "Medusa Store" hardcoded | **P0** |
| Meta descriptions | ⚠️ Product pages use title as description | **P0** |
| Canonical URLs | ❌ Missing on most pages | **P0** |
| Open Graph tags | ⚠️ Only on product pages | **P1** |
| Twitter Card tags | ❌ No explicit config beyond fallback image | **P1** |
| JSON-LD Structured Data | ❌ None | **P1** |
| Sitemap | ⚠️ Legacy `next-sitemap.js` with wrong env var | **P1** |
| robots.txt | ⚠️ Generated by legacy config only | **P1** |
| Google Analytics | ❌ Not installed | **P2** |
| Google Search Console | ❌ Not verified | **P2** |
| Hreflang / i18n | ❌ Not implemented despite `[countryCode]` routing | **P3** |
| Image alt text | ⚠️ Inconsistent | **P3** |
| Internal linking | ✅ Uses `next/link` | OK |
| Core Web Vitals monitoring | ✅ Vercel Speed Insights | OK |
| Image optimization | ✅ `next/image` with CDN | OK |
| Font optimization | ✅ `next/font/google` | OK |
| SSG / ISR | ✅ Products, collections, categories pre-built | OK |

## Sitemap & Crawling Audit

### Current Sitemap Config — `storefront/next-sitemap.js`

```javascript
// CURRENT STATE
module.exports = {
  siteUrl: process.env.NEXT_PUBLIC_VERCEL_URL,  // ← wrong env var
  generateRobotsTxt: true,
  exclude: excludedPaths + ["/[sitemap]"],       // ← array + string = broken concat
  robotsTxtOptions: {
    policies: [
      { userAgent: "*", allow: "/" },
      { userAgent: "*", disallow: ["/checkout", "/account/*"] },
    ],
  },
}
```

**Issues:**
1. `siteUrl` uses `NEXT_PUBLIC_VERCEL_URL` — this is the Vercel deployment URL (e.g., `storefront-abc.vercel.app`), not the canonical domain (`elvato.shop`)
2. `exclude` concatenation is broken — `["/checkout","/account/*"] + ["/[sitemap]"]` produces a string, not an array
3. Uses legacy `next-sitemap` package approach instead of App Router native `sitemap.ts`
4. Missing pages: `/about`, `/design-services`, `/how-it-works`
5. Not dynamically generating product/collection/category URLs with `lastModified` dates

### robots.txt

No standalone `robots.ts` file exists. Generated by `next-sitemap.js` at build time with the broken `siteUrl`.

**Missing disallow rules for:** `/cart`, `/demo`, `/order/*`

## Technical Infrastructure (What's Working Well)

### Rendering Strategy ✅
- **SSG with ISR** for products, collections, and categories via `generateStaticParams()`
- Server-side rendering ensures all content is in the initial HTML — critical for crawl budget
- 5-minute ISR revalidation for cache misses

### Image Optimization ✅
- `next/image` used throughout for automatic WebP conversion, lazy loading, and responsive sizing
- CDN images served via Bunny CDN (Convex integration) with Redis-cached URLs
- Multiple remote image domains whitelisted in `next.config.js`

### Font Optimization ✅
- `next/font/google` with Fraunces — zero extra network requests, font CSS inlined at build time

### Analytics ✅
- Vercel Analytics (real user monitoring)
- Vercel Speed Insights (Core Web Vitals tracking)

### Internal Linking ✅
- `LocalizedClientLink` component wraps `next/link` for country-code-prefixed navigation
- Breadcrumb navigation exists on category pages
